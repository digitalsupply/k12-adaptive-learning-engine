不用出题，只做自评

自评不产生客观作答记录，只作为掌握度的弱证据参与衰减。

如何使用

  1. 左上选择学段/科目，选中一个知识点（默认以知识链呈现它的先修脉络）
  2. 点「练习一下」答题；AI 命题的题干选项都是完整自然的句子
  3. 答错点「归因此错」沿先修链找病根
  4. 点「学习路径」生成分阶段补救计划

先修关系只在同一学科同学段内成立。需要全科大图时切「🗺 全景图」。
